Одне ядро — весь доступний світ

Так-2-Так не має змушувати людину ходити по десятках сайтів і додатків. Людина формулює потребу один раз. Ядро працює замість неї.

Ядро: розуміє намір → визначає географію → збирає дані з власної бази та підключених джерел/API → нормалізує → перевіряє → порівнює → ранжує → показує до 3 найкращих реальних варіантів.

Прозорість: результат показує, чому він у топі. Платне приховане просування не впливає на ранжування.

Масштаб: нові системи підключаються як адаптери до ядра без перебудови застосунку.

Налаштування ядра

Хмарне ядро

Firebase уже підключений до цієї програми. У нормальній роботі всі користувачі працюють через одну спільну хмарну базу.

Проєкт: tak-2-tak
База: Firebase Realtime Database
Акаунти: Firebase Authentication
Конфігурація хмари вбудована в програму.

Інтеграції ядра

Відкриті джерела та реєстри можна підключати до ядра без перебудови програми. Закриті сервіси підключаються через їхні офіційні API/угоди/дозволи.
